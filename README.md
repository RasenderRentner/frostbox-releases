# Frostbox · Versionen

Hier liegen die fertigen Versionen von Frostbox, einem privaten Player für Serien und Filme
von archive.org (Windows 10 und 11).

- **Neu einrichten:** unter „Releases“ die neueste `Frostbox-…-Installation.zip` laden,
  entpacken und `Frostbox.exe` starten. Die beiliegende `Anleitung.txt` erklärt alles.
- **Aktualisieren:** Frostbox findet neue Versionen selbst („Nach Updates suchen“). Oder du
  ziehst die `Frostbox-…-Update.zip` auf das Frostbox-Fenster.

Jedes Update trägt ein Echtheitssiegel. Frostbox nimmt nur Updates vom Entwickler an.
